# AEOWUN Zero

This project is born out of a simple problem:

**AEOWUN needs a brain.**

Not another chatbot, coding assistant, or wrapper around an existing model. AEOWUN is being built to understand software, reason about it, work on it, and eventually engineer it. To do that, it needs a model built around the problems AEOWUN is actually trying to solve.

That is **AEOWUN Zero**.

## 1. Why Zero-A Exists

The goal isn't to create a model that knows everything. It is to create a model that understands what AEOWUN actually needs: **architecture, structure, relationships, intent, behavior, constraints, invariants, tools, and the difference between what might be true and what has actually been established.**

LLMs are powerful at reasoning and interpretation, but they can confidently make things up. Deterministic systems provide structure and validation, but can become rigid.

**AEOWUN needs both.**

## 2. The Zero-A Approach

Zero-A is the attempt to bridge neural reasoning and deterministic engineering.

| Capability             | Neural Reasoning | Deterministic Systems |
| :--------------------- | :--------------- | :-------------------- |
| Interpretation         | **Strong**       | Limited               |
| Generalization         | **Strong**       | Limited               |
| Structural constraints | Variable         | **Strong**            |
| Validation             | Variable         | **Strong**            |
| Evidence               | Indirect         | **Direct**            |
| Adaptability           | **Strong**       | Limited               |

Zero-A is intended to provide a common layer between these two approaches rather than forcing either one to replace the other.

The model can reason without its reasoning automatically becoming truth. The system can verify without requiring everything to be reduced to rigid rules.

## 3. The Goal

The long-term objective is straightforward:

**Build a model that doesn't just get used by AEOWUN, but becomes part of how AEOWUN understands software.**

Zero-A is therefore being developed as more than a standalone language model. It is intended to become part of the semantic foundation through which AEOWUN can interpret architectural intent, understand system structure, reason about invariants, and connect neural reasoning with deterministic execution.

## 4. Current Status

**Experimental / Active Development**

Zero-A is currently being trained and evaluated as part of the broader AEOWUN development effort.

The model, training process, architecture, and evaluation methodology are expected to change as experimentation continues.
